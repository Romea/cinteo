# cinteo_hardware

## 1) Overview

`cinteo_hardware` provides the live `ros2_control` hardware plugin for the Cinteo mobile base.

It specializes the generic `1FAS2RWD` hardware abstraction from `romea_mobile_base_hardware` and is intended to connect it to the Cinteo low-level controller.

The exported plugin is:

| Plugin | Base class | Mobile base architecture |
|---|---|---|
| `cinteo_hardware/CinteoHardware` | `HardwareSystemInterface1FAS2RWD` | `1FAS2RWD` |

## 2) Hardware concept

`CinteoHardware` is loaded by `controller_manager` from the `<ros2_control>` description generated by `cinteo_description`.

At runtime, it:

1. reads the Cinteo `ros2_control` hardware information;
2. creates the `HardwareInterface1FAS2RWD` command and state interface mapping;
3. exposes the front axle steering command interface;
4. exposes the rear left and rear right wheel speed command interfaces;
5. converts controller commands into Cinteo hardware command variables;
6. converts Cinteo feedback variables into `ros2_control` state interfaces.

From the controller point of view, this behaves like a standard mobile base hardware plugin: `romea_mobile_base_controllers/MobileBaseController1FAS2RWD` writes the front axle steering command and the rear wheel speed commands, then reads feedback from state interfaces to compute odometry.

## 3) Low-level communication

The plugin currently contains the `ros2_control` integration and the `1FAS2RWD` command/state mapping.

The concrete low-level communication with the real Cinteo platform is planned and will be added in this package.

The low-level communication methods are the extension points used to connect the plugin to the real Cinteo platform:

* `connect_()` and `disconnect_()` handle the hardware lifecycle;
* `read()` updates front axle steering and rear wheel speed feedback;
* `write()` sends the current front axle steering and rear wheel speed commands;
* `send_command_()` and `send_null_command_()` are the platform-specific command hooks.

## 4) Relation with other packages

`cinteo_hardware` is the live hardware specialization of the Cinteo mobile base:

* `cinteo_description` selects `cinteo_hardware/CinteoHardware` in `live` mode;
* `romea_mobile_base_hardware` provides the reusable `1FAS2RWD` hardware abstraction;
* `romea_mobile_base_utils` provides helpers used to read `hardware_interface::HardwareInfo`;
* `romea_mobile_base_controllers` sends commands through the exported `ros2_control` interfaces;
* `cinteo_bringup` starts the controller manager and loads this hardware plugin in live mode.
